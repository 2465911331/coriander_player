# Material Design 3 界面实现（1.5.7）

实施日期：2026-10-22。承接 `material-design-3-optimization-plan.md`。

## 技能来源

已先审阅再安装 MADTeacher/mad-agents-skills 的 `flutter-adaptive-ui` 与 `flutter-animations`，安装于用户技能目录。应用了约束驱动的自适应布局、共享组件、状态保留、唯一 Hero 标识、最小化动效与减少动画策略；未增加运行时依赖。

## 实现

| 方案 | 本版实现 |
| --- | --- |
| 独立播放区 | PlayerWorkspace 将页面与 PlayerDock 分开布局；页面无需预留遮挡补偿。上一首、播放、下一首、队列按钮独立响应。 |
| 状态一致 | AudioTile 列表/卡片共同监听播放状态；SongListItem 复用于歌曲与队列；焦点、选择和当前播放使用独立提示。 |
| 主题与文字 | AppDesign 定义文字、卡片、菜单、对话框及表面颜色；行高根据实际 TextScaler 计算。 |
| 工具栏 | 分段视图切换、已选排序提示、内容宽度决定动作收纳；切换列表/卡片时尽量保留浏览位置。 |
| 搜索 | SearchAnchor/SearchBar 提供本地建议、全部结果、清空、空状态；Ctrl+F 进入或聚焦搜索。 |
| 设置 | 五个分类页、保留分类滚动位置、窄布局自动上下排列标签和控件。 |
| 删除反馈 | 歌单删除后提供 6 秒撤销；保存去抖并保留原歌曲文件。 |
| 播放页连续性 | 底部封面到播放页的 Hero 过渡；飞行只绘制静态封面，不额外启动音频或频谱实例。 |
| 辅助队列 | 主界面逻辑宽度至少 1120 时使用侧栏，否则弹出面板；播放详情至少 1280 时允许歌词与队列并列。 |
| 动效策略 | AppMotion 统一过渡时间和曲线，读取用户关闭动效、系统减少动画与 TickerMode；保留已有后台省电策略。 |
| 键盘返回 | Esc 经焦点链处理，优先关闭面板，再返回页面；播放快捷键注册去重，焦点异步更新串行处理。 |

## 验证原则

新增测试覆盖 540/900/1440 逻辑宽度、1/2 倍文字、底部布局与点击隔离、滚动位置保留、播放/选择状态、减少动画、可中断封面过渡、搜索与删除撤销。最终实测结果以发布目录中的“验证记录.txt”为准。

本版不宣称完整的无障碍认证、所有显示缩放组合覆盖或已完成逐帧性能基准。采用 Flutter 3.32.8 自带组件和现有技术栈，不引入尚未适配的新版框架能力。
